# IssueFlow – Ticket Management Backend Platform
**TDP 2026 Home Assignment**

## Tech Stack
- TypeScript 5.x
- NestJS 10
- TypeORM
- PostgreSQL
- JWT Authentication
- Jest (unit tests)

## Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Start the database
```bash
docker compose up -d
```

### 3. Create uploads folder
```bash
mkdir uploads
```

### 4. Run the app
```bash
npm run start:dev
```

### 5. Run tests
```bash
npm test
```
